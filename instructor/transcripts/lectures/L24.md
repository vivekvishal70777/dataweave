## Interview beat — Q14. How do you transform JSON to XML (and vice versa)?

**SAY:**

Change the `output` MIME type and shape the tree:

```dataweave
%dw 2.0
output application/xml
---
orders: {
  order: payload map {
    id: $.id,
    amount: $.amount
  }
}
```

JSON to XML needs a **single root**. XML to JSON is the reverse: `output application/json` and select elements/attributes (`payload.orders.order.@id` for attributes).
