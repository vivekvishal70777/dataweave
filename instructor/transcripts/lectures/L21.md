## Interview beat — Q12. How do you write if/else in DataWeave?

**SAY:**

DataWeave uses expressions, not statements:

```dataweave
if (payload.age >= 18) "adult"
else if (payload.age >= 13) "teen"
else "child"
```

There is no ternary `? :` operator like Java.
