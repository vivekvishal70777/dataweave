## Interview beat — Q4. How do you declare a variable in DataWeave?

**SAY:**

Use `var` in the header (script-scoped) or inside a `do` block.

```dataweave
%dw 2.0
output application/json
var taxRate = 0.18
---
{
  total: payload.amount * (1 + taxRate)
}
```

Variables are immutable.

## Interview beat — Q6. What are the main DataWeave data types?

**SAY:**

`String`, `Boolean`, `Number`, `Date`, `DateTime`, `LocalDateTime`, `Time`, `Period`, `Regex`, `Array`, `Object`, `Null`, `Binary`, `Type`, and `Any`. Type annotations are optional but useful in interviews and modules:

```dataweave
fun add(a: Number, b: Number): Number = a + b
```

## Interview beat — Q7. How do you convert types (`as`)?

**SAY:**

Use `as` for coercion:

```dataweave
payload.age as Number
payload.createdAt as Date {format: "yyyy-MM-dd"}
payload as String {encoding: "UTF-8"}
```

If coercion fails, the script errors unless you use `try` / `default`.
