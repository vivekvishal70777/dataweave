Q65. Which number helpers should you name?

  • sum, avg, min, max, mod, abs, ceil, floor, round, plus money via as String {format: "0.00"} as Number.
  • Coerce ERP strings before arithmetic. sum([]) is a common trap — skip empty or default 0.
  • Do not use Java BigDecimal unless the interviewer asks; fun money is the DW answer.
