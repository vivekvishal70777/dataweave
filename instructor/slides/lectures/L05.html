Q1. What is DataWeave?

  • DataWeave is MuleSoft’s functional data transformation language.
  • In Mule 4 it is the primary way to map, filter, enrich, and convert payloads between formats such as JSON, XML, CSV, Java objects, and strings.
  • Scripts run inside the Transform Message component and also as DataWeave expressions (#[...]) in other processors.
