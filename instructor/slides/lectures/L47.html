  • Harder variant: recursive diff for nested objects/arrays (walk both trees with match on types).

Type this

%dw 2.0
output application/json
var old = vars.oldPayload
var newp = payload
---
namesOf(newp) filter ((k) -> old[k] != newp[k]) map (k) -> {
  field: k,
  from: old[k],
  to: newp[k]
}

Q54. How do you implement pagination-style take / drop / windows on arrays?

  • Also: slice(array, from, until), divideBy(array, n) for chunking (e.g. batch API calls).
  • Mention memory: drop/take on a streamed payload may still force materialization.
L47

Type this

%dw 2.0
import * from dw::core::Arrays
output application/json
var page = vars.page default 1
var size = vars.pageSize default 20
---
payload drop ((page - 1) * size) take size
