Q38. How do you call Java from DataWeave? When should you not?

  • You can invoke static methods and, with care, instance methods. Prefer pure DataWeave for transformations.
  • Use Java for libraries you cannot reproduce (special crypto, proprietary parsers). Java calls add coupling and can hurt streaming/performance.

Q40. How do you use lookup (Mule 4) vs DataWeave-only alternatives?

  • Flow lookup (from dw::Runtime / Mule functions) invokes another flow and returns its payload—useful for enrichment, but it is synchronous and expensive.
  • Prefer lookup tables as objects, groupBy, database/HTTP connectors outside Transform Message, or Mule::p() for config.
  • Mention in interviews: do not hide heavy I/O inside every map iteration if you can batch it.
