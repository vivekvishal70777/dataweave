Q14. How do you transform JSON to XML (and vice versa)?

  • Change the output MIME type and shape the tree:
  • JSON to XML needs a single root.
  • XML to JSON is the reverse: output application/json and select elements/attributes (payload.orders.order.@id for attributes).

  order: payload map {

    amount: $.amount
  }
