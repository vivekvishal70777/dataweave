# Quiz 2 — Arrays

1. `map` returns:
   - A) An object
   - B) An array
   - C) A Boolean
   - D) XML attributes

2. In `payload map { index: $$, value: $ }`, `$$` is:
   - A) The previous item
   - B) The current item
   - C) The index (0-based)
   - D) The MIME type

3. `filter` keeps elements where the predicate is:
   - A) `null`
   - B) `false`
   - C) `true`
   - D) a Number

4. `flatten` on nested arrays:
   - A) Recursively flattens all levels
   - B) Flattens **one** level
   - C) Converts to JSON string
   - D) Removes duplicates

5. Prefer `isEmpty(x)` over:
   - A) `x default []`
   - B) `sizeOf(x) == 0`
   - C) `map`
   - D) `output application/json`
