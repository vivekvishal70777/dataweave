# Final practice test — Interview bootcamp

Use interview rules: no notes, 20 minutes.

1. Write (on paper) the three parts of a DataWeave 2 script.
2. When do you use `mapObject` instead of `map`?
3. How do you read an XML attribute vs a child element?
4. Why is `lookup` inside `map` a performance smell?
5. Name three operations that break streaming.
6. How do you build a dynamic key in an object literal?
7. `distinctBy` keeps first or last?
8. `default` vs `try` — one sentence each.
9. Sketch `flatMap` for order → line items.
10. Talk through XML namespace in → canonical JSON out (Q60): reader, types, totals, where I/O does **not** belong.

Compare afterward with `sections/12-interview-bootcamp/LECTURE.md` and the [whiteboard set](../resources/whiteboard.md).
